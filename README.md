# Nali-Metroidvania

Proyecto de videojuego desarrollado con Unity **6000.2.8f1**.

## Abrir el proyecto

1. Instala Unity Editor `6000.2.8f1` desde Unity Hub.
2. En Unity Hub, selecciona **Add** y elige la carpeta raíz del repositorio.
3. Abre el proyecto. Unity restaurará los paquetes declarados en `Packages/manifest.json`.

El código y los recursos están en `Assets/`; la configuración necesaria del proyecto está en `ProjectSettings/`. Las carpetas generadas por Unity, como `Library/`, `Temp/` y `Logs/`, se excluyen mediante `.gitignore` y se regeneran al abrir el proyecto.
